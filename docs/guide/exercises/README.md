# Exercises

Progressive exercises. Do them in order. Each one forces you to confront a production gap before showing the Naro reference.

## Levels

1. [Minimal safe loop](01-minimal-safe-loop.md) — authorization + verification
2. [Governance and approval](02-governance.md) — human gate + identity
3. [Evidence and audit](03-evidence-and-audit.md) — hash chain + evidence record

Each exercise includes steps, expected artifacts, and a pointer to the Naro implementation that already solves it.

More levels (data contracts, cost budgets, multi-agent boundaries) will be added as the guide matures.
