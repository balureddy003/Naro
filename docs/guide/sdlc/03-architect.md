# 3. Architect

## Goal

Choose the system shape and record the load-bearing decisions.

## Activities

- Select single-agent vs multi-agent
- Decide verification placement, approval style, model neutrality, data-contract strictness, and hands isolation
- Identify trust boundaries and external systems
- Sketch the core loop and evidence flow

## Key artifact

One or more **Architecture Decision Records** plus a one-page system context diagram.

## Exit gate

Major decisions are written down, alternatives are noted, and the team agrees.
