Implements ADRs 0014–0022:

- **0014** `EscalatingReasoner` (@naro/reasoning): tiered child reasoners,
  escalate after N failed verifications — cost-aware escalation as a
  reasoner, not a kernel primitive.
- **0015** `McpRegistryServer` requires a `HarnessKernel` and routes
  `tools/call` through it (see mcp-server-gated changeset).
- **0016** `Tool.definitionHash`: remote sources pin the advertised
  definition; a changed hash emits `tool.definition.changed` and forces
  the tool to `destructive` until `acknowledgeDefinition()`. External
  tool descriptions are delimited as untrusted in transcripts.
- **0017** `PolicyContext.principal` + `AgentDeps.principal`: the
  delegated principal is a policy input; `naro serve` threads the
  authenticated caller through the runner factory.
- **0018** Attested retention pruning: `journal.retention.pruned` marker
  event, `PrunableEventStore` on `SqliteEventStore`/`PgEventStore`,
  `naro prune` CLI, and `verifyChain` re-anchors on `anchorHash` with a
  disclosed `pruned` verdict.
- **0019** `MemoryInput.trust`/`MemoryEntry.trust`/`MemoryHit.trust`:
  write-time provenance round-trips through every store.
- **0020** `ToolRegistry` tracks source ids: a second source claiming a
  name emits `tool.collision.detected` and stays shadowed until
  `resolve(name, sourceId)`.
- **0021** `OtlpSpanExporter` (@naro/adapter-otel): GenAI-convention spans
  to `/v1/traces` — one agent span per run, `execute_tool` spans per
  action, shared `trace_id` across delegated runs.
- **0022** `POST /runs/:id/cancel` (operator) + `POST /runs/cancel-all`
  (admin): reason required, `by` attribution journaled on
  `agent.cancelled`.
